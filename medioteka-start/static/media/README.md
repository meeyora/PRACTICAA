# Учебные образцы видео

sample.mp4 — H.264, 640×360, около 12 секунд, без звуковой дорожки.
sample.webm — VP8, 640×360, около 12 секунд, без звуковой дорожки.
Оба файла содержат один синтетический сюжет с секундомером и движением.
Видео созданы специально для комплекта. Разрешено использовать и изменять их в учебных целях.
sample.vtt — браузерные субтитры; sample.srt — те же реплики для VLC.
Проверены получение метаданных и загрузка обоих форматов в Chromium.
Поддержку, управление и субтитры в установленном Firefox и VLC исследуйте в блоке 6.
