# Размещение заготовки в GitFlic

Преподаватель создаёт пустой проект GitFlic без автоматически добавленного README.
Извлеките архив в новую папку. До первого коммита проверьте git status.
В терминале этой папки выполните:

```text
git init -b main
git add .
git commit -m "Добавить исходную версию учебного проекта"
git remote add origin АДРЕС_ПУСТОГО_ПРОЕКТА_ИЗ_GITFLIC
git push -u origin main
git tag start
git push origin start
```

Подставьте точный адрес проекта из интерфейса GitFlic. Строка с АДРЕСОМ является шаблоном.
Если Git сообщает, что автор не настроен, задайте имя и учебную почту локально для этого репозитория.
Настройку входа и токенов выполняйте самостоятельно, токен в файлы проекта не записывайте.
В существующий непустой проект эту последовательность не применяйте: используйте отдельный пустой проект.

Распределите роли участников и рецензентов. Защиту main и условия слияния настройте по возможностям своей версии и тарифа.
Базовая практика работает с локальным запуском тестов. CI/CD подключается преподавателем после проверки агента и конфигурации.
