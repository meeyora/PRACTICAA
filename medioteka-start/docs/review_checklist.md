# Критерии ревью

- Есть связанная проблема и ссылка на требование.
- Изменение устраняет заявленную причину.
- Проверены обычный случай и граница.
- Тест способен обнаружить прежнюю ошибку.
- Остальные функции сохраняют поведение.
- Имена, структура и сообщения понятны.
- Документация соответствует фактической работе.
- В изменениях нет секретов и ненужных файлов.
- Замечание содержит место, причину и способ проверки.
- Автор ответил на каждое замечание, повторная проверка зафиксирована.
