# Требования к учебному продукту

1. Каталог содержит шесть учебных записей. Названия материалов условные, видео служат тестовыми образцами.
2. Поиск находит подстроку в названии без учёта регистра. Пробелы по краям запроса игнорируются.
3. Пустой запрос показывает все записи.
4. Выбор категории оставляет только записи этой категории. Пустая категория показывает все записи.
5. Суммарная длительность равна сумме duration всех показанных записей.
6. Проверка записи отклоняет пустое название и duration <= 0. Для заданий тип duration считается целым числом.
7. duration_label принимает целое неотрицательное число секунд. Примеры: 60 = «1 мин», 3661 = «1 ч 1 мин 1 с».
8. Неизвестный номер видео возвращает HTTP 404.
9. Видео имеет доступные элементы управления, помещается в окно шириной 375 px и поддерживает выбор имеющихся субтитров.
10. Форма /login только учебная. Аутентификации, базы паролей и регистрации нет. Настоящие пароли запрещены.
11. /privacy работает только с учебным ключом practice-theme в localStorage. Внешних трекеров нет.
12. /lab выполняет одинаковый расчёт. Контрольная сумма должна совпадать во всех повторах.

Изменение кода сопровождают проверкой соответствующего требования и повторным запуском остальных тестов.
